
### Rules

#### 1. 시퀀스 길이에 따른 데이터 분포
문장당 동작 개수: 1개 ~ 5개, 각각 20%씩 균등 비율로 생성

#### 2. 시간 (n초)

**적용 여부**
| action | 적용 여부 |
|---|---|
| search | 미적용 (1분간 찾아본 후 없으면 넘어가는 별도 설계) |
| resume | 미적용 |
| move / perform / stop | 적용 가능, 생략 가능 (생략 시 기본값 5초) |
 
**표현 형식**<br>n초 / n초만 / n초 동안 / n초 만큼 / n초간 / n초쯤 / n초정도 / n초간만 / n초 동안만 / n초 내내
 
**접두사**<br>위 표현 앞에 "한 / 딱 / 정확히"가 붙을 수 있음

접두사가 붙지 않을 확률 50%, "한"/"딱"/"정확히"가 붙을 확률 각각 약 16.7%로 설계<br>(`["", "", "", "한 ", "딱 ", "정확히 "]` 중 균등 확률로 하나를 선택하는 방식)
 
#### 3. 반복 (n번)

**적용 여부**
| action | 적용 여부 |
|---|---|
| search / resume | 미적용 |
| move / perform / stop | 적용 가능, 생략 가능 (생략 시 기본값 1번) |
 
#### 4. 속도 (n하게)

속도의 종류에는 slow / normal / fast가 있음

**적용 여부**
| action | 적용 여부 |
|---|---|
| search / stop / resume | 미적용 |
| move / perform | 적용 가능 |

**구성**: 부사형과 고정 표현을 합쳐 균등 확률로 하나를 선택 
| 구분 | 부사형 | 고정 표현 |
|---|---|---|
| 빠른 속도 | 빠르게, 신나게, 빨리, 얼른, 급하게, 후다닥 | 빠른 속도로, 빠름으로, 고속으로 |
| 느린 속도 | 느리게, 천천히, 느긋하게, 느림으로, 여유롭게 | 느린 속도로, 저속으로 |

#### 8. stop / resume 규칙

**stop**
- 시퀀스 어디든 위치 가능
- stop-stop 연속 배치 금지
**resume**
- 시퀀스 맨 앞에는 올 수 없으며 맨 뒤에는 위치 가능
- stop이 최소 한 번 나온 뒤 등장
- resume-resume 연속 배치 금지
 
#### 9. 응답(상태) 생성 관련
 
- 로봇 응답은 "강쥐", "멍멍이" 같은 단어를 쓰지 않고 표준 명사만 등장
- 응답 데이터 비중을 최대한 늘림 (오버샘플링)
